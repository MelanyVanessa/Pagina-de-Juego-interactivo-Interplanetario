# 🚀 Viaje Interplanetario VR

Página web del proyecto de la clase de **Tecnologías Inmersivas**: un juego interactivo hecho en Unity en el que los niños, con gafas de realidad virtual, exploran los planetas del Sistema Solar y sus órbitas.

Sitio estático (HTML + CSS + JS) basado en la plantilla *College* de [BootstrapMade](https://bootstrapmade.com/license/).

## Ver la página en local

Abre `index.html` en el navegador.

## Publicar con GitHub Pages

1. Sube el proyecto a un repositorio de GitHub.
2. En el repositorio ve a **Settings → Pages**.
3. En **Source** elige `Deploy from a branch`, la rama `main` y la carpeta `/ (root)`.
4. Guarda; en unos minutos la página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
